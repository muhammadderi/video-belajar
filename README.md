# 🎥 Video Belajar

Aplikasi web untuk mengelola dan menampilkan video pembelajaran secara interaktif. Dibangun menggunakan React dan Tailwind CSS.

## ✨ Fitur

- Autentikasi pengguna (Login & Register)
- Daftar video pembelajaran
- Filter dan pencarian
- Update profil pengguna

## ⚙️ Teknologi

- React.js
- Tailwind CSS
- React Router
- Zustand (state management)
- Axios (API request)

## 🚀 Cara Menjalankan

```bash
git clone https://github.com/muhammadderi/video-belajar.git
cd video-belajar
npm install
npm run dev
